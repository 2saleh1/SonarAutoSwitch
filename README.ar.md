# برنامج SonarAutoSwitch 🎧

> **محول الصوت التلقائي الذكي لبرنامج SteelSeries Sonar**  
> يقوم بتحويل جميع قنوات الصوت في SteelSeries Sonar (`Game`, `Chat`, `Media`, `Aux`, `Monitoring`) إلى سماعة البلوتوث أو سماعة الأولوية فور تشغيلها واتصالها، ويعيد الصوت تلقائياً لسماعتك الأساسية عند إيقاف تشغيلها.

---

## 💡 لماذا نحتاج هذا البرنامج؟
برنامج **SteelSeries Sonar** يحتوي على ميزة "Backup Device Switch"، لكنها مصممة بحيث **لا تحول الصوت إلا إذا انفصل الجهاز الحالي**.
إذا كانت سماعتك الأساسية (مثل HyperX) موصولة بالسلك طوال الوقت، ثم قمت بتشغيل سماعة البلوتوث (مثل TOZO أو AirPods):
- سونار **لن** يحول الصوت تلقائياً لأن السماعة الأساسية لا زالت متصلة!
- تضطر كل مرة لفتح البرنامج والتحويل يدوياً.

**SonarAutoSwitch** يحل هذه المشكلة تماماً بمراقبة النظام وتحويل الصوت عبر واجهة Sonar البرمجية الداخلية فور اتصال السماعة وبأقل من ثانية واحدة، مع الحفاظ على جودة المايكروفون عبر السلك.

---

## 🚀 التثبيت بنقرة واحدة (1-Click)

1. حمّل المستودع أو انسخه:
   ```cmd
   git clone https://github.com/2saleh1/SonarAutoSwitch.git
   cd SonarAutoSwitch
   ```
2. اضغط مرتين على ملف **`install.bat`**.
3. هذا كل شيء!
   - سيتم بناء البرنامج ووضعه في مسار التطبيقات.
   - سيتم إضافة اختصار التشغيل التلقائي مع بدء تشغيل الويندوز.
   - ستظهر أيقونة البرنامج (سماعة) بجانب الساعة في شريط المهام (System Tray).

---

## ⚙️ التحكم والإعدادات

- **اضغط مرتين على أيقونة البرنامج بجانب الساعة** (أو كليك يمين ➔ **Settings**):
  - **قائمة الأولويات (Fallback Priority):** اختر سماعتك من القائمة المنسدلة واضغط `Add Detected` أو اكتب اسم السماعة (مثل `TOZO` أو `AirPods`) واضغط `Add Keyword`.
  - يمكنك ترتيب الأولويات للأعلى والأسفل بالأزرار `▲ Up` و `▼ Down`.
  - **الجهاز الافتراضي (Default Device):** اختر سماعتك السلكية الأساسية (مثل `HyperX`).
  - **الإشعارات:** فعّل أو عطّل ظهور إشعارات الويندوز عند التبديل.
  - اضغط **Save & Apply** لحفظ الإعدادات وتطبيقها فوراً.

---

## 📂 ملفات المشروع

- `src/Program.cs`: نقطة انطلاق البرنامج وأيقونة شريط المهام ومحرك المراقبة.
- `src/SettingsForm.cs`: واجهة الإعدادات الداكنة العصرية لإدارة الأجهزة.
- `src/SonarClient.cs`: الاتصال بـ API سونار وتحويل القنوات.
- `src/AudioHelper.cs`: التعرف الذكي على أجهزة الصوت في ويندوز.
- `src/Config.cs`: حفظ وتحميل الإعدادات في ملف `config.json`.
- `build.bat`: تجميع الكود المصدري.
- `install.bat`: التثبيت بنقرة واحدة والتسجيل مع بدء تشغيل الويندوز.
- `uninstall.bat`: إزالة البرنامج بالكامل.

---

## 🗑️ إزالة التثبيت
لحذف البرنامج، فقط شغّل ملف `uninstall.bat`.
